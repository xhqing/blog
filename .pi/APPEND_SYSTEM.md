# blog（藏经阁）项目硬约束

本文件由 pi 在项目根目录启动会话时自动追加进系统提示，只列硬规则；详细说明看 `AGENTS.md`。

1. **带 `<!-- source: … -->` 标记的文章是自动同步产出，不要手改**——下次同步会被覆盖。要改内容，改 `social-agent` 仓库里的源文章（`docs/articles/`）。
2. **`docs/_sidebar.md` 与 `docs/README.md` 是生成物**，由 `deploy.py` 生成；手改会在下次构建时被覆盖。要新增分类就新建目录，要调顺序就给文章加 `<!-- order: N -->`。
3. **文章体例**：首行 `创建于 YYYY-MM-DD<br>`，标题用二级 `##`——一级标题会让 docsify 侧边栏多出一层。
4. **改完跑 `python3 scripts/validate.py`**，通过再提交。
5. **推送即上线**：`main` 分支的 `docs/` 直接就是线上站点，别往 `docs/` 放草稿文件或临时产物；临时文件放 `tmp/`（已忽略）。
