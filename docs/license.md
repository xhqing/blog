下面这份说明是便于阅读的版本。有法律意义的只有 CC BY 4.0 官方全文，两者理解不一致时，以官方全文为准。

## 你可以做什么

- **复制、分发**：整篇转载、打印、放进公司内部资料库、做成 PDF 分享；
- **改编**：节选、翻译、重新组织、配上自己的解读；
- **商用**：课程讲义、付费专栏、书籍章节、培训材料、内部分享。

以上都不需要事先联系我，不用申请，也不用付费。条件只有下面三条。

## 需要做的三件事

1. **署名**：写明作者“xhqing”，并给出原文链接；
2. **标注许可**：写明内容基于 CC BY 4.0 授权，附上许可链接 <https://creativecommons.org/licenses/by/4.0/>；
3. **说明改动**：删了段落、改了措辞、翻译成别的语言，都说明改了什么。原样转载就写“未作修改”。

还有一条不作为义务、但值得做：如果方便，把转载的地址发我一个，我好知道文章去了哪儿。

## 署名怎么写

可以直接抄下面的句式，把尖括号里的内容换成实际信息。

整篇转载：

> 本文作者 xhqing，原载于“藏经阁”：〈原文链接〉。基于 CC BY 4.0 许可转载，未作修改。

节选或翻译：

> 本文节选自 xhqing 的《〈文章标题〉》（〈原文链接〉），基于 CC BY 4.0 许可节选并翻译。

英文场景：

> Adapted from “〈Article Title〉” by xhqing (〈original URL〉), licensed under CC BY 4.0 (<https://creativecommons.org/licenses/by/4.0/>). Changes were made.
